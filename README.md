## Chiasm ##
A pair of glasses aimed to help visually imparied people navigate today's world safely. This project enables real-time object detection using YOLO on a Mac M1 (2020 release), while handling telemetry using OpenTelemetry and eBPF on a Linux Virtual Machine.

## Prototype ##

I opted for Impact Resistant working glasses and Wired Bone Conduction Headphones. To make them one unit I applied velcro to the both of the glasses frame ends and attached the oppoiste side that locks and holds them together to the headphone frame; This allows for re-sizing according to head shape making it widely accessible for training entities.


## Hardware ##
Camera -> Arducam 8MP IMX179 USB Camera Module (Wind Angle Lightburn webcam with 115^(H) M12 lens, Single Microphone)

GPS Tracking -> Stemedu VK172 GPS Module USB G-Mouse Dongle Reciever Tracker

Camera Sensor -> Seeed Studio XIAO ESP32 S3 Sense (2.4GHz WIFI, BLE 5.0, OV2640 Camera Sensor, Digital Microphone)

Headphones -> E&P Wired Bone Conduction Headphones with Microphone

Glasses -> ANSI Z87.1 Work Glasses
